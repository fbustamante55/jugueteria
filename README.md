# Product Management System

A Java console application for managing product inventory, including CRUD operations and stock tracking.

## Technologies
- Java 11+
- Object-Oriented Programming

## Features
- Add, edit, and delete products
- Stock level tracking
- Category management
- Search and filter products
- Console menu interface

## Getting Started
```bash
javac Main.java
java Main
```
